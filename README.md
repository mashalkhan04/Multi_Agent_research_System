# ResearchMind – AI Multi-Agent Research Assistant

ResearchMind is an AI-powered multi-agent research assistant designed to automate the process of searching, analyzing, writing, and reviewing information. Instead of manually browsing multiple sources, users can simply enter a topic, and the system uses specialized AI agents to generate a structured research response.

This project is built using **Streamlit**, **LangChain**, **LangGraph**, and **OpenAI**, demonstrating how agentic AI workflows can be used to solve real-world productivity and research problems.

---

## Project Description

ResearchMind is a smart research automation system that uses multiple AI agents to work together like a small research team. Each agent has a specific role, such as searching for information, reading content, writing the final answer, and reviewing the quality of the response.

The main goal of this project is to reduce manual research effort and help users generate reliable, detailed, and well-structured information on any topic.

This project is useful for students, researchers, professionals, content writers, and anyone who wants quick research assistance.
